Первый выпуск простого приложения «Мои финансы» для Android 5.0 и новее.

- Таблица доходов и расходов: дата, описание, сумма дохода, сумма расхода.
- Добавление записей с выбором даты и удаление с подтверждением.
- Подсчёт общих доходов, расходов и остатка.
- Сохранение записей на телефоне без базы данных и сервера.

При первом запуске показаны три примера операций. Их можно удалить и ввести свои данные. Денежные суммы хранятся в целых копейках.

Вложения: установочный APK и ZIP исходников с README для Android Studio.

Сборка, тесты денежных сумм и Android Lint выполняются в GitHub Actions. Запуск на реальном телефоне отдельно не проверялся. Используется отладочная подпись: если подпись новой сборки отличается, может потребоваться переустановка с удалением локальных данных.
